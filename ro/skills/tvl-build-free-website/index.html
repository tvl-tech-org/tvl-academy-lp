Skill pentru Website Gratuit

tvl-build-free-website ajută un agent AI să construiască un website static, să îl publice pe GitHub Pages și să verifice URL-ul live.

Instalează skill-ulÎnapoi la skills
Ce construiește

Site-uri statice compatibile cu GitHub Pages

Site de serviciu

O pagină compactă pentru companie, serviciu, eveniment sau campanie, cu ofertă clară, dovadă și contact.

Portofoliu

Profil profesional cu proiecte, studii de caz, semnale de credibilitate și linkuri de contact.

Hub de documentație

Site public pentru un proiect sau o resursă, cu quick start, ghiduri, exemple și referințe.

Moduri de publicare

  • Deploy din branch, din main root sau /docs.
  • Deploy cu GitHub Actions pentru output static generat.
  • .nojekyll când asseturile statice trebuie să evite procesarea Jekyll.

Verificări obligatorii

  • index.html există în rădăcina publicată.
  • Căile către asseturi funcționează sub URL-uri de project page.
  • Nu sunt comise secrete sau date private.

Verificare live

  • Deploymentul Pages trece cu succes.
  • URL-ul live răspunde cu HTTP 200.
  • Titlul, H1, CSS, imaginile și navigația sunt verificate.
Instalare și rulare

Adaugă skill-ul pentru website-uri

Instalează cu Agent Skills CLI

$ npx skills add danlex/tvl-skills --skill tvl-build-free-website

Cere-i direct lui ChatGPT sau Codex să îl instaleze

Install the Agent Skill tvl-build-free-website from https://github.com/danlex/tvl-skills and verify that it is available for this workspace.

Cere-i direct lui Claude Code să îl instaleze

Install the skill tvl-build-free-website from danlex/tvl-skills into Claude Code, then list the installed skills to confirm it is available.

Rulează skill-ul după instalare

Use $tvl-build-free-website to build a one-page service website for this offer and publish it for free with GitHub Pages.

Skill-ul este pentru website-uri statice. GitHub Pages nu este hosting de backend și nu trebuie folosit pentru baze de date, secrete runtime, date private sau autentificare server-side.
