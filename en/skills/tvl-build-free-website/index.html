Build Free Website Skill

tvl-build-free-website helps an AI agent build a static website, publish it on GitHub Pages, and verify the live URL.

Install the skillBack to skills
What it builds

Static sites that can run on GitHub Pages

One-page service site

A compact company, service, event or campaign page with a clear offer, proof and contact path.

Portfolio

A professional profile with projects, case studies, credibility signals and contact links.

Documentation hub

A public project or resource site with quick start, guides, examples and reference links.

Deployment modes

  • Branch deploy from main root or /docs.
  • GitHub Actions deploy for generated static output.
  • .nojekyll when static assets should bypass Jekyll processing.

Required checks

  • index.html exists at the publishing root.
  • Asset paths work under project-page URLs.
  • No secrets or private data are committed.

Live verification

  • Pages deployment succeeds.
  • Live URL returns HTTP 200.
  • Title, H1, CSS, images and navigation are verified.
Install and run

Add the website builder skill

Install with the Agent Skills CLI

$ npx skills add danlex/tvl-skills --skill tvl-build-free-website

Ask ChatGPT or Codex to install it

Install the Agent Skill tvl-build-free-website from https://github.com/danlex/tvl-skills and verify that it is available for this workspace.

Ask Claude Code to install it

Install the skill tvl-build-free-website from danlex/tvl-skills into Claude Code, then list the installed skills to confirm it is available.

Run it after install

Use $tvl-build-free-website to build a one-page service website for this offer and publish it for free with GitHub Pages.

The skill is designed for static websites only. GitHub Pages is not a backend host and should not be used for databases, runtime secrets, private data or server-side authentication.
