LinkedIn Post Writing Skill

tvl-write-linkedin-post turns source material into a structured LinkedIn post using CROFTAFC and LinkedIn Writing Protocol v3.

Install the skillBack to skills
Purpose

What the skill does

Structured input

Extracts context, role, objective, facts, tasks, audience, format and constraints before drafting.

LinkedIn-native output

Builds a post that is clear, evidence-based and designed for professional readers rather than generic promotion.

Validation

Runs deterministic checks and revises the draft when length, structure or protocol requirements fail.

Use when

  • You need a technical LinkedIn post from a paper, launch note, article or internal brief.
  • You want a repeatable writing protocol instead of a one-off prompt.
  • You need the AI to preserve facts and avoid vague thought-leadership filler.
Install and run

Add the LinkedIn skill

$ npx skills add danlex/tvl-skills --skill tvl-write-linkedin-post
Use $tvl-write-linkedin-post to turn this product update into a 2,700 to 2,900 character LinkedIn post.
