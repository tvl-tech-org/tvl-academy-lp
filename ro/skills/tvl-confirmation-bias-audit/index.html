Skill Confirmation Bias Audit

tvl-confirmation-bias-audit verifică dacă o concluzie a fost atinsă prin căutarea dovezilor care confirmă ipoteza inițială.

Instalează skill-ulÎnapoi la skills
Metodă

Falsificare înainte de concluzie

Alternativa este formulată

Numește cea mai puternică alternativă plauzibilă înainte să accepte concluzia.

Alternativa este testată

Verifică dacă au fost căutate dovezi contrare sau teste de falsificare.

Certitudinea este calibrată

Semnalează afirmațiile puternice când dovezile susțin doar o ipoteză.

Cazuri comune

  • RCA și incident triage.
  • Răspunsuri chatbot care validează framingul utilizatorului.
  • Code review cu afirmații precum "safe", "unused" sau "no vulnerability".
  • Recomandări business bazate pe dovezi înguste sau unilaterale.
Instalare și rulare

Adaugă skill-ul confirmation bias

$ npx skills add danlex/tvl-skills --skill tvl-confirmation-bias-audit
Folosește $tvl-confirmation-bias-audit ca să auditezi acest RCA pentru dovezi unilaterale și alternative lipsă.
