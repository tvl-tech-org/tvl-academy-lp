Confirmation Bias Audit Skill

tvl-confirmation-bias-audit checks whether a conclusion was reached by looking mainly for evidence that supports an initial hypothesis.

Install the skillBack to skills
Audit method

Falsification first

Alternative stated

Names the strongest plausible alternative before accepting the conclusion.

Alternative tested

Checks whether disconfirming evidence or counter-tests were actually sought.

Certainty calibrated

Flags strong claims when the evidence supports only a hypothesis.

Common use cases

  • Root-cause analysis and incident triage.
  • Chatbot advice that validates a user's framing.
  • Code review conclusions such as "safe", "unused" or "no vulnerability".
  • Business recommendations based on narrow or one-sided evidence.
Install and run

Add the confirmation bias skill

$ npx skills add danlex/tvl-skills --skill tvl-confirmation-bias-audit
Use $tvl-confirmation-bias-audit to audit this RCA for one-sided evidence and missing alternatives.
