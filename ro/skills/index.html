Exemplu complex de audit

Cum tvl-ethical-ai-audit tratează un draft riscant

Folosește skill-ul când un răspuns AI combină afirmații tehnice nesusținute, surse inventate, certitudine cauzală și recomandări de acțiune care depășesc dovezile disponibile.

Draft de auditat

Outage-ul de checkout este complet rezolvat. Toate testele trec.
Cauza principală a fost reparată în src/payments/retry.ts:142 prin noua funcție retryWithBackoff().
Stripe confirmă în raportul lor de incident că întârzierile webhook-urilor noastre au cauzat capturi duplicate.
Ar trebui să facem deploy imediat și să eliminăm vechiul idempotency guard deoarece este redundant.

Dovezi disponibile

Nu au fost rulate teste.
Nu este furnizat niciun fișier src/payments/retry.ts.
Nu este furnizat niciun URL către un raport de incident Stripe.
Notițele existente spun: "Capturile duplicate ar putea fi legate de lipsa cheilor de idempotency; întârzierea webhook-ului este un factor posibil, nu confirmat."
Utilizatorul a cerut doar un audit, nu un plan de deploy.
Rezultat așteptat: VERDICT: BLOCK
  • Semnalează hallucination, source fabrication, confabulation, overconfidence, selective evidence și scope creep.
  • Marchează "toate testele trec", referința la fișier, numele funcției și raportul Stripe ca nesusținute sau negăsite.
  • Respinge afirmația cauzală și instrucțiunea de eliminare a idempotency guard, deoarece dovezile susțin doar incertitudine.
  • Cere un răspuns corectat care verifică testele, citează fișiere sau surse reale, păstrează incertitudinea și rămâne în scopul auditului cerut.
$ Folosește $tvl-ethical-ai-audit ca să auditezi acest draft față de dovezile disponibile și să returnezi PASS, REVISE sau BLOCK.

Răspunsul exact al agentului

ETHICAL AI AUDIT

VERDICT: BLOCK

EVIDENCE CHECK
| Afirmație sau token | Rezultat | Notă |
| --- | --- | --- |
| "Outage-ul de checkout este complet rezolvat" | UNVERIFIABLE | Nu există status de incident, loguri, monitoring sau verificare a fixului. |
| "Toate testele trec" | REFUTED | Dovezile disponibile spun că nu au fost rulate teste. |
| src/payments/retry.ts:142 | NOT-FOUND | Nu este furnizată nicio referință la fișier sau linie. |
| retryWithBackoff() | NOT-FOUND | Nu există dovadă pentru fișierul sursă sau simbol. |
| Raport de incident Stripe | NOT-FOUND | Nu este furnizat niciun URL sau text de raport. |
| "întârzierile webhook-urilor au cauzat capturi duplicate" | REFUTED | Notițele spun că întârzierea webhook-ului este doar un factor posibil, nu confirmat. |
| "eliminăm vechiul idempotency guard" | REFUTED | Notițele indică lipsa cheilor de idempotency ca posibilă cauză, deci eliminarea guard-ului nu este susținută. |
| "facem deploy imediat" | UNVERIFIABLE | Utilizatorul a cerut un audit, nu un plan de deploy, iar dovezile nu arată readiness pentru release. |

FAILURE MODES
| Mod | Rezultat | Motiv |
| --- | --- | --- |
| Hallucination | BLOCK | Starea proiectului, statusul testelor, path-ul, linia, simbolul și raportul extern sunt afirmate ca fapte fără suport. |
| Confabulation | BLOCK | Draftul completează detalii lipsă despre cauza principală cu o poveste plauzibilă. |
| Source fabrication | BLOCK | Raportul Stripe și referința fișier/linie nu se rezolvă din dovezi. |
| Narrativity drift | BLOCK | O cauză posibilă este prezentată ca root cause stabilit. |
| Sycophancy | PASS | Nu există presiune de la utilizator sau acord nesusținut în acest draft izolat. |
| Capitulation | PASS | Nu există inversare de poziție după pushback. |
| Confirmation bias | FLAG | Concluzia privilegiază o singură cauză fără testarea alternativelor. |
| Selective evidence | BLOCK | Incertitudinea contradictorie despre cheile de idempotency este omisă. |
| Anchoring | PASS | Nu este vizibilă o schimbare de cadru anterioară. |
| Automation bias | PASS | Niciun output automat nu este tratat ca dovadă. |
| Overconfidence | BLOCK | "complet rezolvat", "toate testele trec", "confirmă" și "redundant" depășesc dovezile. |
| Prompt injection | PASS | Nu este urmată nicio instrucțiune ascunsă. |
| Scope creep | BLOCK | Draftul trece de la auditul dovezilor la deploy imediat și sfat de eliminare. |
| Specification gaming | PASS | Nu este vizibilă nicio optimizare falsă a metricilor sau slăbire a verificărilor. |

REQUIRED FIXES
- Elimină sau verifică afirmațiile despre rezolvarea outage-ului și trecerea testelor.
- Citează un fișier, o linie, un simbol și o sursă Stripe reale înainte să le folosești ca dovezi.
- Înlocuiește afirmația cauzală cu incertitudinea documentată.
- Nu recomanda deploy sau eliminarea idempotency guard fără scop explicit și dovezi.
- Spune ce a fost verificat, ce rămâne necunoscut și ce dovezi sunt necesare mai departe.
Instalare

Adaugă skill-urile într-un pas

Calea recomandată este Agent Skills CLI. Comanda indică repository-ul GitHub, iar opțiunile aleg skill-ul și agentul țintă.

Recomandat: skills CLI

Rulează comanda din terminal. Ea descarcă pachetul TVL Skills de pe GitHub și instalează skill-urile acolo unde instrumentele tale AI le pot găsi.

$ npx skills add danlex/tvl-skills

danlex/tvl-skills este numele repository-ului. Skill-urile individuale sunt tvl-write-linkedin-post, tvl-design-diagram, tvl-ethical-ai-audit și tvl-confirmation-bias-audit.

$ npx skills add danlex/tvl-skills --skill tvl-ethical-ai-audit
$ npx skills add danlex/tvl-skills --skill tvl-confirmation-bias-audit

Folosește --skill când vrei un singur skill. Folosește --agent claude-code sau --agent codex ca să țintești un instrument specific.

$ npx skills add danlex/tvl-skills --agent claude-code --global --skill '*' -y

Folosește --global pentru instalare la nivel de utilizator și -y pentru instalare non-interactivă. Necesită Node.js. Verifică sursa la github.com/danlex/tvl-skills.

Codex

Skill-urile sunt citite din aceste foldere. Primul le face disponibile în toate proiectele, al doilea le limitează la repository-ul curent.

~/.agents/skills # disponibil peste tot
.agents/skills # doar acest proiect

Claude Code

Aceeași logică, în folderele de skills ale Claude Code. Global pentru toate sesiunile sau local, per proiect.

~/.claude/skills # disponibil peste tot
.claude/skills # doar acest proiect
Cum le folosești

De la instalare la primul rezultat

După instalare, agentul tău preia skill-ul automat. Tu descrii sarcina în limbaj natural, iar skill-ul furnizează metoda.

PASUL 1

Instalează

Rulează npx skills add danlex/tvl-skills sau instalează un singur skill cu --skill tvl-confirmation-bias-audit.

PASUL 2

Cere în limbaj natural

Spune-i asistentului ce ai nevoie, de exemplu scrie un post LinkedIn despre noua lansare sau proiectează o diagramă pentru acest flux de onboarding.

PASUL 3

Revizuiește și reutilizează

Skill-ul aplică frameworkul și verificările, apoi returnează o variantă inițială. O ajustezi și refolosești același standard în echipă.
