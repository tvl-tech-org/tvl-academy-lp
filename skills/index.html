Install

Add the skills in one step

The recommended path is the Agent Skills CLI. The command points to the GitHub repository, then optional flags choose the skill and target agent.

Recommended: skills CLI

Run this from your terminal. It fetches the TVL skills package from GitHub and installs the skills where your agent tools can find them.

$ npx skills add danlex/tvl-skills

danlex/tvl-skills is the repository name. The individual skills are tvl-write-linkedin-post and tvl-design-diagram.

$ npx skills add danlex/tvl-skills --skill tvl-design-diagram

Use --skill when you want only one skill. Use --agent claude-code or --agent codex to target a specific tool.

$ npx skills add danlex/tvl-skills --agent claude-code --global --skill '*' -y

Use --global for a user-wide install and -y for a non-interactive install. Requires Node.js. Review the source at github.com/danlex/tvl-skills.

Codex

Skills are read from these folders. Use the first for skills available in every project, the second for skills scoped to one repository.

~/.agents/skills # available everywhere
.agents/skills # this project only

Claude Code

Same idea, in the Claude Code skills folders. Global for all sessions, or per-project inside the repository.

~/.claude/skills # available everywhere
.claude/skills # this project only
How to use

From install to first result

Once a skill is installed, your agent picks it up automatically. You describe the task in plain language and the skill supplies the method.

STEP 1

Install

Run npx skills add danlex/tvl-skills, or install one skill with --skill tvl-design-diagram.

STEP 2

Ask in plain language

Tell your assistant what you need, for example write a LinkedIn post about our new release or design a diagram of this onboarding flow.

STEP 3

Review and reuse

The skill applies its framework and checks, then returns a draft. Refine it, and reuse the same standard across your team.
