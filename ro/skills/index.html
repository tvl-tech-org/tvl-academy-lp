Cum funcționează

De la instalare la rezultat structurat

Un skill este un set reutilizabil de instrucțiuni pe care asistentul AI îl încarcă la cerere. Îl instalezi o dată, apoi îl invoci ori de câte ori sarcina se potrivește.

1

Instalezi skill-urile

O singură comandă copiază skill-urile din repository-ul public GitHub în instrumentul tău Agent Skills.

Funcționează în Claude Code, ChatGPT/Codex și instrumente compatibile
2

Invoci un skill

Menționezi skill-ul după nume — de exemplu $tvl-seo-geo-audit — sau descrii sarcina și lași asistentul să aleagă skill-ul potrivit.

Aceleași instrucțiuni, același comportament, la fiecare rulare
3

Verifici rezultatul

Fiecare skill returnează un format definit: o postare LinkedIn validată, o diagramă Mermaid sau un raport de audit cu verdicte clare.

Rezultate structurate, pe care le verifici, nu le ghicești
Instalare rapidă

Adaugă skill-urile în instrumentele tale

Toate skill-urile stau în repository-ul public TVL Skills și se instalează cu Agent Skills CLI.

Instalează toate skill-urile TVL

$ npx skills add danlex/tvl-skills

Instalează un singur skill

$ npx skills add danlex/tvl-skills --skill tvl-seo-geo-audit

Cere lui Claude Code să instaleze unul

Instalează skill-ul tvl-write-linkedin-post din danlex/tvl-skills în Claude Code, apoi listează skill-urile instalate pentru a confirma că este disponibil.

Exemplu de prompt

Folosește $tvl-seo-geo-audit pentru a audita https://academy.tvl.tech/ro/skills/ pentru SEO tehnic, accesibilitate, structured data, multilingual hygiene și vizibilitate în răspunsuri AI.
