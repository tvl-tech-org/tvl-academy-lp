Ethical AI Audit Skill

tvl-ethical-ai-audit checks AI-generated drafts, claims, citations and plans before they are trusted or published.

Install the skillBack to skills
Audit scope

Failure modes covered

Evidence failures

Hallucination, confabulation, source fabrication and unsupported citations.

Reasoning failures

Confirmation bias, selective evidence, anchoring, narrativity drift and overconfidence.

Agent behavior

Sycophancy, capitulation, prompt injection, scope creep and specification gaming.

Output

The skill returns an evidence-first report with PASS, REVISE or BLOCK, then lists concrete fixes. It does not rewrite the draft unless asked.

Install and run

Add the Ethical AI skill

$ npx skills add danlex/tvl-skills --skill tvl-ethical-ai-audit
Use $tvl-ethical-ai-audit to audit this draft before I publish it.
