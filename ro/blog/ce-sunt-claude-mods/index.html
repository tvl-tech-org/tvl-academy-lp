Ce sunt Claude mods și ce pot face în Claude Code?

de Alexandru Dan · 5 octombrie 2026 · 7 min de citit

Un mod Claude este o mică extensie care schimbă felul în care lucrează Claude Code chiar în timp ce îl folosești. Îl scrii în JavaScript sau TypeScript, rulează în interiorul Claude Code și reacționează chiar în clipa în care trimiți un prompt, în care Claude apelează un instrument sau în care ecranul e pe cale să se redeseneze.

Un exemplu scurt lămurește lucrurile. Să zicem că vrei să ții socoteala câte instrumente a folosit Claude într-o sesiune. Un mod poate urmări fiecare apel de instrument, poate adăuga unu la un contor și poate afișa numărul lângă indicatorul de așteptare cât timp Claude lucrează. Un mod ascultă un eveniment, apoi îl urmărește, îl ajustează sau se ocupă el de el. Anthropic a prezentat mods în documentația Claude Code și le-a anunțat pe 1 octombrie 2026.

Mods au nevoie de Claude Code v2.1.287 sau mai nou, unde suportul este activ din start, așa că o versiune recentă le acceptă; rulează claude --version ca să vezi versiunea ta. Asta înseamnă că funcția e pornită, nu că ai deja instalat vreun mod făcut de altcineva. Dacă ai activat vechiul comutator CLAUDE_CODE_ENABLE_FUNCTION_HOOKS în perioada de acces timpuriu, îl poți lăsa deoparte, pentru că versiunile actuale îl ignoră (cum pornești sau oprești mods).

Ce construiesc oamenii cu ele

Skills, settings hooks, liniile de stare și serverele MCP stau toate în afara Claude Code. Un mod stă înăuntru, de aceea poate face lucruri la care celelalte nu ajung (ce poate face un mod):

  • Pune pe ecran ceva ce poți folosi: un panou lateral sau o bandă deasupra promptului, cu butoane și câmpuri în care scrii.
  • Schimbă părți din ecran pe care Claude Code le desenează singur, cum ar fi felul în care arată un apel de instrument sau indicatorul de așteptare.
  • Adaugă propria ta comandă slash, care îți rulează codul pe loc, fără să aștepte un răspuns de la model.
  • Se așază în fața unui apel de instrument sau a unei cereri: îl pune în pauză ca să te întrebe ceva, îi răspunde fără să ruleze instrumentul sau trimite o anumită cerere către alt model.
  • Lasă părțile sale să folosească în comun aceleași date, așa încât o valoare pe care o reține o parte poate apărea în alta.

Prin ce diferă un mod de un skill, un settings hook și un server MCP

Aceste patru personalizări se suprapun. Tabelul arată ce este fiecare și când să apelezi la ea.

TipCe esteCe scriiPoate desena interfață
ModFuncții dintr-un plugin pe care Claude Code le apelează în propriul procesJavaScript sau TypeScriptDa
Settings hookO comandă de shell, o cerere HTTP sau un prompt pe care Claude Code le rulează la un eveniment din ciclul de viațăUn script și o intrare în setăriNu
SkillUn set de instrucțiuni pe care Claude le citește când o cere sarcinaMarkdownNu
Server MCPUn proces extern care îi dă lui Claude instrumenteUn server în orice limbajNu

Un singur plugin poate purta la un loc un mod, un skill, settings hooks și un server MCP, așa că lucrează împreună; o alegi pe cea care se potrivește sarcinii.

Cum obții un mod

Nu trebuie să scrii tu unul ca să vezi un mod în acțiune: unele dintre funcțiile proprii ale Claude Code sunt mods, printre care comanda /diff, care îți arată modificările în așteptare (mods incluse în Claude Code). Ca să adaugi modul altcuiva, îl instalezi ca plugin dintr-un marketplace, cu o comandă de forma /plugin install nume@marketplace, unde nume și marketplace sunt doar exemple.

Unde rulează mods

Codul unui mod rulează în orice sesiune care îi încarcă plugin-ul (unde rulează mods). Rulează într-un terminal, inclusiv terminalul integrat al unui editor, și în fila Code a aplicației desktop Claude, mai puțin într-o sesiune WSL de acolo, unde plugin-urile nu se încarcă deloc. În chatul extensiei VS Code, în claude -p și în Agent SDK rulează, dar nu desenează nimic; într-o sesiune din cloud rulează doar când plugin-ul ajunge în acea sesiune. Interfața unui mod apare în mai puține locuri decât rulează codul lui: terminalul arată tot ce desenează, iar aplicația desktop arată tot, în afară de câteva elemente disponibile doar în terminal. Un mod care desenează poate verifica unde se află și poate reveni la text simplu acolo unde nu poate desena.

La ce ajunge un mod și cum îl verifici întâi

Un mod este cod care rulează cu permisiunile tale și nu este izolat într-un sandbox (la ce ajunge un mod). Odată încărcat, poate citi și scrie orice fișiere la care ajunge contul tău, poate rula programe și poate face cereri în rețea; poate citi variabilele tale de mediu și setările, inclusiv o cheie de API ținută acolo; poate vedea fiecare prompt și fiecare apel de instrument; poate rescrie un prompt sau un apel de instrument; și poate aproba un apel de instrument înainte să fii întrebat. Poate restiliza mare parte din interfață, dar nu fereastra de permisiune. De aceea, instalează mods doar de la autori și din marketplace-uri în care ai încredere. Înainte să instalezi unul, claude plugin validate pe folderul lui enumeră hook-urile și apelurile de API pe care modul le declară (ce face un mod). Asta nu e tot ce va face modul și nu este un audit de securitate sau o garanție că modul este sigur; dacă îl iei doar de la autori în care ai încredere scazi riscul, dar nu îl dovedești.

Mods și modelul

Un mod lucrează asupra software-ului din jurul modelului. Poate rescrie un prompt înainte să fie trimis, poate direcționa o cerere către alt model sau poate adăuga o comandă care îți rulează codul fără niciun apel către model. Nu antrenează suplimentar Claude și nu îi editează ponderile. O comandă rulează fără un pas al modelului doar atunci când funcția ta nu apelează ea însăși un model; când apelează unul, acea cerere se scade din planul sau din cheia ta de API ca oricare alta.

Întrebări frecvente

Ce este un mod Claude, pe scurt?
Un mic supliment, scris în JavaScript sau TypeScript, care rulează în interiorul Claude Code și reacționează la evenimente precum un prompt, un apel de instrument sau o redesenare a ecranului. Poate urmări un eveniment, îl poate schimba sau se poate ocupa de el, așa că îți poți adăuga propriile panouri, comenzi și reguli.

Trebuie să instalez ceva ca să folosesc mods?
Mods au nevoie de Claude Code v2.1.287 sau mai nou, unde suportul este activ din start, deci o versiune recentă le acceptă; rulează claude --version ca să verifici. Mods incluse, precum comanda /diff, sunt deja acolo, dar un mod făcut de altcineva se instalează separat, ca plugin dintr-un marketplace în care ai încredere.

Sunt mods sigure de instalat?
Un mod rulează cu permisiunile tale și nu este izolat într-un sandbox, așa că poate ajunge la fișierele, secretele și sesiunea ta și poate face cereri în rețea. claude plugin validate enumeră hook-urile și apelurile pe care un mod le declară, dar asta nu este un audit de securitate și nu dovedește că e sigur, așa că instalează doar de la autori și din marketplace-uri în care ai încredere.
