Diagram Design Skill

tvl-design-diagram turns rough notes, architecture descriptions and process flows into readable Mermaid diagrams.

Install the skillBack to skills
Templates

Three diagram modes

System map

Actors, components, stores, integrations and outputs.

Workflow

Ordered steps, handoffs, review loops and final outputs.

Decision flow

Validation gates, branches and PASS/FLAG/BLOCK outcomes.

Quality check

  • Chooses the simplest diagram type that fits the task.
  • Marks uncertain edges instead of inventing flow.
  • Runs a lightweight Ethical AI check before returning the diagram.
Install and run

Add the diagram skill

$ npx skills add danlex/tvl-skills --skill tvl-design-diagram
Use $tvl-design-diagram to turn this onboarding workflow into a Mermaid diagram.
