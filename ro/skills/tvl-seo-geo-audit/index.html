Skill SEO/GEO Audit

tvl-seo-geo-audit ajută un agent AI să verifice o pagină pentru vizibilitate în search, conținut randat, Core Web Vitals, Bing/IndexNow, WCAG 2.2, spam policy, rich results, Lighthouse performance, structured data, SEO multilingv și pregătire pentru răspunsuri AI. Skill-ul returnează dovezi, priorități și pași clari.

Concepte

SEO, GEO și accesibilitate

Ce este SEO?

SEO înseamnă să faci o pagină ușor de accesat, înțeles și evaluat de motoarele de căutare și de oameni. Include indexabilitate tehnică, metadate clare, conținut util, linkuri interne, structured data și dovezi verificabile.

Ce este GEO?

GEO, sau generative engine optimization, urmărește dacă sistemele AI de răspuns pot înțelege, sintetiza și cita o pagină. Nu garantează citări AI. Optimizează ce poate fi controlat: claritate, crawlability, structură, fapte, surse și măsurare.

Ce este accesibilitatea?

Accesibilitatea înseamnă ca pagina să poată fi folosită de oameni cu abilități, dispozitive și tehnologii asistive diferite. Ajută și înțelegerea de către mașini: headinguri semantice, linkuri descriptive, alt text, contrast, navigare cu tastatura și limbaj clar.

Reguli on-page

Ce verifică skill-ul

Arie Regulă SEO/GEO
IndexabilitatePagina trebuie să returneze statusul HTTP corect, să evite noindex accidental și să fie crawlable când se dorește vizibilitate publică.
Canonical și hreflangCanonicalul trebuie să indice pagina de limbă corectă. Paginile multilingve au nevoie de hreflang reciproc și valori HTML lang corecte.
MetadateTitlul și descrierea trebuie să fie exacte, specifice, lizibile și fără promisiuni nesusținute.
Structura conținutuluiFolosește un H1 clar, secțiuni H2/H3 logice, definiții scurte, answer blocks, exemple și afirmații susținute de surse.
Structured dataJSON-LD trebuie să fie valid, relevant și aliniat cu textul vizibil din pagină.
AccesibilitateFolosește HTML semantic, linkuri descriptive, contrast adecvat, controale accesibile din tastatură și alt text pentru imaginile cu sens.
LighthouseCând există browser tooling, rulează Lighthouse pentru Performance, Accessibility și SEO. Tratează rezultatul ca evidență de laborator, nu ca garanție de ranking sau Core Web Vitals de teren.
Core Web VitalsSepară Lighthouse lab data de field data. Verifică LCP, INP și CLS cu CrUX, PageSpeed Insights sau Search Console când există acces.
Bing și IndexNowVerifică Bingbot policy, Bing Webmaster Tools și IndexNow separat de dovezile Google. Nu promite vizibilitate în Copilot.
WCAG 2.2Mapează accesibilitatea pe Perceivable, Operable, Understandable și Robust. Automatizarea nu dovedește conformitate WCAG completă.
Spam policyMarchează scaled content abuse, doorway behavior, cloaking, expired-domain abuse și reputation borrowing când există dovezi.
Rich resultsValidează structured data după tipul paginii: Article, Product, LocalBusiness, Course, Video, FAQ, Organization și consistența cu textul vizibil.
Integritatea surselorVerifică dacă sursele citate sunt accesibile, relevante, actuale și susțin afirmația de lângă ele.
Crawler logsCând există loguri, verifică vizitele crawlerelor după user agent, status, URL și timestamp. Fără loguri, marchează NOT_TESTED.
Vizibilitate în răspunsuri AIAfirmațiile factuale trebuie să fie ușor de extras și citat. Evită copy vag, conținut ascuns și promisiuni GEO nemăsurate.
MăsurareDefinește cum verifici impactul SEO/GEO: Search Console, referral analytics, index coverage și verificări AI answer datate.

Prompt pentru browser și Lighthouse

Use $tvl-seo-geo-audit to audit this page. If browser access is available, compare raw HTML with the rendered DOM and run Lighthouse for Performance, Accessibility, and SEO. Clearly label unavailable checks as NOT_TESTED.

Prompt pentru audit P0/P1 extins

Use $tvl-seo-geo-audit to run the expanded SEO/GEO audit. Include Core Web Vitals field data, Bing/IndexNow, WCAG 2.2, Google spam-policy risk, rich-result eligibility by page type, image/video SEO, citation integrity, optional SERP comparison, and crawler-log verification. Label unavailable evidence as NOT_TESTED.

Folosește $tvl-seo-geo-audit ca să auditezi https://academy.tvl.tech/ro/skills/ pentru SEO tehnic, accesibilitate, structured data, SEO multilingv și vizibilitate în răspunsuri AI.
